# RPG-Temp-name

APEX DREAMFORGE is a Godot 4 project. This repository is the project folder.

## Open

1. Install Godot 4.7 stable. This project was checked with Godot 4.7.2 (standard editor, not .NET).
2. In the Godot Project Manager, choose Import and select this folder (the folder that contains `project.godot`).
3. Open the project. The main scene is `res://main.tscn`.

## Run

In the editor, press F5 or the Play button. The window title is APEX DREAMFORGE.

From a terminal, with the Godot 4.7 binary on your PATH as `godot`:

```
godot --path .
```

Load check (exit code 0 means the project loaded):

```
godot --headless --path . --quit-after 1
```
